How this guide works

Theory first

Every module opens with a short, plain-English explanation of the concept — no prior Flink experience assumed.

Then practice

Each module has a hands-on widget: predict real output, drag a window size, trigger a simulated failure, run SQL.

Progress that sticks

Pass a module's quiz and it's marked complete in your browser's local storage — no account needed, nothing leaves your device.

Built as a static site — no backend, no build step. Hosted free on GitHub Pages. See CONTRIBUTING.md for the branch & PR workflow.
