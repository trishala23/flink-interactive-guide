DataStream API

MethodSignature shapeWhat it does
mapDataStream<T> → DataStream<R>1:1 transform
flatMapDataStream<T> → DataStream<R>1:N transform
filterDataStream<T> → DataStream<T>Keep elements matching a predicate
keyByDataStream<T> → KeyedStream<T,K>Logical partition by key; required for keyed state/aggregation
sum / min / maxKeyedStream → DataStreamRolling aggregation, one output per input
reduceKeyedStream<T> → DataStream<T>Custom rolling combine function
windowKeyedStream → WindowedStreamGroup into tumbling/sliding/session windows
connectDataStream, DataStream → ConnectedStreamsCombine two streams while keeping their types distinct
process→ DataStreamLow-level API: full access to state and timers
addSink / sinkToDataStream → DataStreamSinkWrite to an external system

Flink CLI

CommandPurpose
flink run my-job.jarSubmit a job to a running cluster
flink run -d my-job.jarSubmit and detach (don't block the terminal)
flink listList running/scheduled jobs
flink cancel <job-id>Cancel a running job
flink stop --savepointPath s3://... <job-id>Stop with a final savepoint
flink savepoint <job-id> s3://...Trigger a savepoint without stopping the job
flink run -s s3://savepoint-path my-job.jarRestart a job from a savepoint

Flink SQL syntax

StatementPurpose
CREATE TABLE t (...) WITH (...)Declare a table backed by a connector (Kafka, filesystem, JDBC, ...)
WATERMARK FOR col AS col - INTERVAL 'n' SECONDDeclare event-time watermarking on a column
SELECT ... FROM t GROUP BY colContinuous aggregation, one updated row per key as data arrives
SELECT ... FROM t GROUP BY TUMBLE(col, INTERVAL 'n' MINUTE)Tumbling window aggregation
CREATE VIEW v AS SELECT ...Name a reusable query
INSERT INTO sink_table SELECT ...Continuously write query results to another table/sink

Core concepts, one line each

TermOne-line definition
JobManagerCoordinates one job: scheduling, checkpoints, recovery.
TaskManagerWorker process that executes operator subtasks in task slots.
Task slotA fixed resource slice on a TaskManager; caps parallelism.
Event timeWhen an event actually happened, per its own timestamp.
WatermarkA claim that no more events earlier than time W should arrive.
CheckpointAutomatic, periodic, whole-pipeline state snapshot for failure recovery.
SavepointManually triggered, portable snapshot for planned operations (upgrades, rescaling).
Keyed statePer-key state (ValueState, ListState, MapState) on a keyed stream.
Exactly-onceEvery event affects state and output exactly once, even after failures — via checkpoints + replayable sources + transactional sinks.
