Module 01

Introduction to Flink

Apache Flink is an open-source engine for processing data streams — unbounded sequences of events — with high throughput, low latency, and exact correctness guarantees even when machines fail.

Why stream processing?

Most real-world data doesn't arrive as a finished dataset — it arrives continuously: clicks, sensor readings, orders, log lines. Traditional batch systems wait until a chunk of data has fully landed (an hour's worth of logs, a day's worth of orders) before processing it. That's simple, but it means insights are always at least one batch late.

Stream processing flips this: instead of waiting for data to accumulate, it processes each event as it arrives, producing results continuously. A fraud-detection rule can fire in milliseconds instead of at the next nightly batch job.

Flink's core idea: batch is just a special case of streaming — a stream that happens to end. Flink's runtime treats bounded and unbounded data with the same engine and largely the same APIs, rather than bolting a "streaming mode" onto a batch engine (or vice versa).

Where Flink fits

Flink isn't the only streaming engine. Here's how it's commonly positioned against two other tools you'll hear mentioned in the same breath:

EngineProcessing modelTypical strength
Apache Flink True event-at-a-time streaming (batch as a special case) Low latency, rich windowing/state, exactly-once semantics
Spark Structured Streaming Micro-batch (very small batches on a fixed interval) One engine for batch + streaming + ML, huge ecosystem
Kafka Streams True event-at-a-time streaming, embedded library No separate cluster — runs inside your application

What Flink is used for

  • Real-time analytics — dashboards and metrics that update as events happen, not once an hour.
  • Fraud & anomaly detection — evaluating rules against a live event stream with millisecond latency.
  • Event-driven applications — triggering workflows the moment a condition in the stream is met.
  • Continuous ETL — keeping a data warehouse or search index up to date as source systems change.
